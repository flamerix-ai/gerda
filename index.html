    Gerda¶

    Gerda — open-source bot framework by Flamerix AI.

    In memory of Gerda, a much-loved dog. This project carries her name.

    Why it exists. Heavy modpacks like Monifactory are wonderful, and they ask for more evenings than most of us have. Gerda is for playing them anyway: send a bot, or an AI agent driving it, to do the routine grind and the boring crafting, and keep the fun parts for yourself.

    Gerda is two things. The harness is a framework for running bot code inside Minecraft on the jsMacros mod: a TCP bridge, an MCP server for LLM operators, screenshots and GUI input, and a worker that drives any Module tick by tick. It works without our bot (harness/bot_template.js). Gerda Bot is our reference bot on top of it: an autonomous ore-mining bot and multi-bot fleet for GregTech CEu (Monifactory, Forge 1.20.1). It plays as a real, non-op player with no extra server-side mods; its only privilege is the pack's FTB Essentials teleport.

    New here? Setup from zero takes you from an empty machine to a driven bot. The repo README has the feature tour, and examples/ has templates from basic to advanced.

    Repo layout and where new code goes¶

    The bot in src/ has three tiers, and imports point only down: core < shared < bot. The defensive checker in bun run check enforces it. The tier table, the full repo layout with where new code goes, and the path of one command and one tick are in How Gerda works. Entry point: src/bot/entry/worker-bundle.ts.
